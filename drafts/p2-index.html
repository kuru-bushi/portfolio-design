P-2 REFINEMENT — THE STARRY NIGHT

《星月夜》洗練パターン一覧

P-2 フローフィールド案のブラッシュアップ版です。共通の改善を全パターンに適用したうえで、右側スクロールバーのデザインを 3 案用意しました。実際に開いてスクロールし、いちばん心地よいものを選んでください。

共通の改善点（全パターン適用済み）

  • 背景の自己回復筆あとが残り続けて背景が濁る問題を修正。毎フレーム元の夜空グラデーションへ少しずつ戻すため、線が通ったあとも数秒で元の色に溶けて戻り、コントラストが保たれます。
  • Works カードの月光ホバーカードにカーソルを乗せると、内側が月光に照らされたように白っぽく明るくなり、文字は夜の藍色に反転します。
  • 左サイドバーPC 表示では画面の縦いっぱいに固定し、内部のスクロールバーは完全に非表示にしました。

右側スクロールバー 3 案

A消灯 — バー非表示

スクロールバーを完全に隠し、画面上部のプログレスバー（少し太く・発光を強化）だけで現在地を示す、最も没入感の高い案。

◎ 絵画への没入感が最大 / △ 現在地の把握は上端のバー頼み

B月光の筆 — 極細ゴールドバー

ネイティブスクロールバーを活かしつつ、月光の金から夜の群青へ流れるグラデーションのピル型サムに再デザイン。ホバーで明るく光ります。

◎ 常時見えて操作性が高い / ◎ CSS のみで軽量

C流星 — 星が軌道を滑る

細い光の軌道の上を、回転しながら光る星「✦」がサムとして滑るオーバーレイ式。スクロールを止めると星ごとふっと消えます。ドラッグでの移動にも対応。

◎ 世界観との一体感が最高 / ◎ 使わない時は消えて邪魔にならない
