## 採用デザイン

**P-2「ゴッホ《星月夜》— 渦巻く夜空のフローフィールド」**（2026-07-24 決定）

- レイアウト: B 案（左サイドバー固定 + 右メインスクロール）
- 背景: 流れ場（フローフィールド）が星月夜の筆致を描き続ける Canvas アニメーション
  - 星・月のまわりに渦、いびつな段階的光輪 + 放射状の光条
  - feTurbulence + feDisplacementMap の SVG フィルタで全体を油絵風に歪ませる
  - 太い筆致・途切れるタッチ・二度描きのインパスト表現
- インタラクション: カスタムカーソル / 空白クリックで星が生まれる / スクロールで夜空が加速 / セクションのリビール / スクロール進捗バー

今後もこの `index.html` を継続的に練っていく。

## デザイン検討ルール

- **候補の提示方法**: サイト候補を複数提示するときは、必ず `drafts/group1-index.html` と同じ形式の比較ページを作る（2 カラムのグリッドに 50% 縮小 iframe を並べ、各セルに「原寸で開く ↗」リンクを付ける）。テキストリンクの一覧だけで提示しない。
- **配色・コントラスト**: 色を変更するときは急な反転や過度な明度差を避け、同じ色彩系統の実在サイトのコントラスト設計を参考にする（例: 暗色系サイトのホバーは明度 +10〜15% 程度に留め、文字色は明るいまま保つ）。
- **参考にするサイト**: デザインを検討・洗練するときは次のジャンルの実例を参考にする。
  - ウェブデザイナーのポートフォリオサイト
  - ウェブデザイン賞を受賞したサイト（Awwwards / CSS Design Awards / FWA など）
  - 画家・アーティストの公式サイト

## 運用ルール

- **1 指示ごとに 1 コミットする**。ユーザーからの 1 つの依頼が完了するたびにコミットし、複数の指示分の変更をまとめて 1 コミットにしない。
- 逆に、1 指示の中で複数ファイルを変更した場合は、それらをまとめて 1 コミットにする（ファイルごとに分割しない）。
- コミットメッセージは、その指示で何を変えたかが後から追えるように書く。
- 指示が調査・確認だけで変更が発生しなかった場合はコミットしない。
