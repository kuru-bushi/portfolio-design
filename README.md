# portfolio-design

エンジニアのポートフォリオサイト。自分の記事と、作成した Web サービスを共有するために使う。

- 公開 URL: https://kuru-bushi.github.io/portfolio-design/
- 草案アーカイブ: https://kuru-bushi.github.io/portfolio-design/drafts/

## 採用デザイン

**P-2「ゴッホ《星月夜》— 渦巻く夜空のフローフィールド」**（2026-07-24 決定）

- レイアウト: B 案（左サイドバー固定 + 右メインスクロール）
- 背景: 流れ場（フローフィールド）が星月夜の筆致を描き続ける Canvas アニメーション
  - 星・月のまわりに渦、いびつな段階的光輪 + 放射状の光条
  - feTurbulence + feDisplacementMap の SVG フィルタで全体を油絵風に歪ませる
  - 太い筆致・途切れるタッチ・二度描きのインパスト表現
- インタラクション: カスタムカーソル / 空白クリックで星が生まれる / スクロールで夜空が加速 / セクションのリビール / スクロール進捗バー

今後もこの `index.html` を継続的に練っていく。

## 構成

```
index.html      … 本サイト（P-2 ベース。今後の開発対象）
drafts/         … 検討過程の草案アーカイブ（保存用・原則編集しない）
  index.html        … 草案の一覧ハブ
  layouts-index.html … 第1段階: レイアウト 4 案の比較
  geo-index.html     … 第2段階: 幾何学テーマ 6 案の比較
  group1-index.html  … 第3段階: 絵画モチーフ 7 案の比較
  mock-*.html        … 各草案本体
```

## 検討の経緯

1. **第 1 段階（レイアウト)**: A ヒーロー+グリッド / B サイドバー固定 / C ミニマル / D ダークビジュアル → **B 採用**
2. **第 2 段階（幾何学テーマ）**: ブループリント / バウハウス / ポリゴン / ラインアート / アイソメトリック / 和柄 → B-4 ラインアートを土台に発展
3. **第 3 段階（絵画モチーフ × 動く背景）**: ミロ / ゴッホ / ボナフェ×ノクターン / ポロック / モンドリアン / エッシャー / カンディンスキー×Ng 26 → **P-2 ゴッホ《星月夜》採用**（P-1・P-5 は凍結）
