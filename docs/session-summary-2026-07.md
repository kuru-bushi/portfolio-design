## レスポンシブ・スマホ仕様（実装済み）

- 900px 以下: サイドバー → 上部固定ヘッダー（IKEDA.K + ハンバーガー）+ 左ドロワー
- スマホ幅（700px 未満）: 背景の流れ速度 **1/2**（ヘッドレス Chrome で PC→スマホ→PC の 1→0.5→1 切り替えをテスト済み）
- **表示アクションは PC / スマホで仕様分離**:
  - PC: ホバー主役。スクロールは初回リビール + セクション見出し強調のみ
  - スマホ: ~~通過グロー~~ → **「中央フォーカス」方式に変更（2026-07-27）**。基準線（画面上から 45%）に最も近い 1 要素だけを常時 `.mfocus`（上下スクロール両対応・同時複数なし・基準線から 30% 超は非アクティブ）。タップ（350ms/12px 以内）で即アクティブ + 次のスクロールまで保持。星の生成はタッチ端末では touchend のタップ判定（LINE 内ブラウザで click が window に届かない対策）
- Codex レビュー: 通過グロー版 `docs/reviews/2026-07-26-codex-scroll-action-review.md` / 中央フォーカス版 `docs/reviews/2026-07-27-codex-mobile-focus-review.md`（重大 0・軽微 1 件は修正済み）
- タッチ端末の低負荷モード（2026-07-27）: SVG 歪みフィルタ無効 + 解像度等倍 + 30fps 間引き。`docs/reviews/2026-07-27-codex-mobile-perf-review.md`
- prefers-reduced-motion で全アニメーション停止
