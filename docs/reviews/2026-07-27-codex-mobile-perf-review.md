# Codex レビュー: タッチ端末の低負荷モード（2026-07-27）

- 対象コミット: 8691bac（工程1: タッチ端末の低負荷モード）
- 対象ファイル: `drafts/mock-p2d2-oilmoon.html` / `drafts/mock-p2e2-impasto.html`
- 実行方法: `codex exec --sandbox read-only`（読み取り専用）
- 重点確認: 既存仕様（PC の挙動 / スマホ速度 1/2 / 通過グロー / reduced-motion / デルタタイム正規化 / タップで星）が変わっていないか

## 変更内容（レビュー対象）

1. `@media (hover: none)` で全画面 SVG 歪みフィルタ `#oilpaint` を無効化
2. タッチ端末はキャンバス内部解像度を等倍に（dpr 上限 2 → 1）
3. タッチ端末は描画を約 30fps に間引き（`minFrame = 1000/30 - 4`。デルタタイム倍率 k で体感速度は不変）

## 計測結果（iPhone エミュレーション + CPU スロットリング、実効フレームレート）

| CPU スロットル | 修正前 | 修正後 |
|---|---|---|
| x4（中スペック相当） | 26.5 fps | 60.4 fps |
| x6（低スペック相当） | 17.8 fps | 45.8 fps |

## 判定結果

- **重大: なし / 中程度: なし / 軽微: なし → 仕様変更なし**

Codex の確認内容（要約）:

- PC（hover あり端末）は SVG フィルタ・DPR 上限 2・毎フレーム描画が維持され、挙動は一切変わらない
- タッチ端末のみ `@media (hover: none)` でフィルタ無効・DPR 上限 1・約 30fps 間引きが適用される
- 幅 700px 未満の背景速度 1/2 は `W < 700` 判定のままで、`hover:none` 判定とは独立しているため維持
- デルタタイム正規化 `k = min(3, dt / (1000/60))` は 30fps 間引き後に適用されるため、60Hz/120Hz いずれのタッチ環境でも進行量に矛盾なし。タブ復帰の k≤3 クランプも従来どおり
- クリック/タップで星を追加し周辺粒子を spawn する処理に変更なし

指摘ゼロのため修正工程（工程3）は不要。
